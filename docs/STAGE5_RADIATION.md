# 가나디: 잿빛 지구 — 5단계 설계·구현 기록

범위: DEVELOPMENT_SPEC.txt §§9~12 및 저장·성능·검사 항목. 4단계 ZIP을 기준으로 새 기능만 추가. 공개 GitHub Pages **미배포**.

## 구현 및 적용 수치

- 하루 600 게임초. 새 게임의 첫 방사능 먼지는 누적 1,800초(3일), 이후 시작 간격은 600초.
- 시작 30초 전 HUD 예고. 60초간 진행. 시각 표현은 반투명 줄무늬 오버레이를 사용하고 화면 확대 및 많은 파티클을 사용하지 않음.
- 보호하지 않은 상태의 연속 2초 노출 시 방사능 디버프. 디버프는 30초 지속, 체력 초당 1, 허기 초당 0.5 추가 감소. 계속 노출되면 남은 시간만 30초로 갱신하며 중첩하지 않음.
- 대피나 방독면은 새 노출을 막지만 이미 발생한 디버프를 없애지 않음. 우유병 음용 시 현재 오염 디버프와 노출 누적값을 제거하며, 다시 2초 노출되면 재감염 가능. 일반 독은 유지하고 즉시 체력 회복 효과를 새로 만들지 않음.
- 일시정지, 비활성 탭, 수면 중 스킵된 시간에는 피해를 한꺼번에 부과하지 않음. 수면 직후 발생 시 예고 없이 노출되는 것을 방지하기 위해 필요하면 해당 이벤트를 다음 600초 주기로 넘김.
- 기존 세이브에서 `stage5` 상태가 없으면 안전한 기본값으로 이주. 기존 진행이 1,800초를 넘었으면 로드 후 **120초의 유예 시간**을 주고 첫 이벤트를 예약. 이벤트 시드/위치는 복제되지 않음.

## 대피소/지하 판정

- 512×160 유한 월드에서 최상단 외부 공기와 연결된 비고체 블록(물 포함)을 다방향 탐색한 결과를 저장하는 캐시 사용.
- 나뭇잎, 열린 문, 열린 공간, 폐광 입구 등 공기가 통과하는 구간은 외부 연결로 처리. 닫힌 문, 밀폐된 구조물, 밀폐된 동굴은 방어 가능.
- 단순히 플레이어 머리 위 한 블록만 있는 지붕은 방어되지 않음. 밝기/직사광선 시스템은 변경하지 않음.
- 블록 설치·채굴·문 개폐가 `world.changed` 이벤트를 내면 캐시 무효화. 1프레임당 최대 12,000개 셀만 처리하는 점진 탐색. 계산 도중에는 신규 노출 시간을 부과하지 않고 HUD에 대피 판정 중을 표시함. 캐시에는 월드의 미로드된 청크까지 `getBlock`을 통해 원본 지형과 사용자 변경 기록이 반영됨.
- 청크가 준비되지 않아 플레이 조작할 수 없는 시점에는 방사능 신규 피해를 부과하지 않음.

## 방독면과 폐광 출처

- 신규 `gas_mask` 아이템: 기존 아이템 ID 뒤에 추가; `material` 종류지만 `stackSize=1`인 예외를 생산 데이터 검증기에 명시적으로 추가. 마스크 아이콘도 별도 추가.
- 기존 자연 생성 보급 상자의 위치/출처/수령 기록(`loot.origins`, `loot.claimed`)을 그대로 사용. `source==='mine'`이고 아직 수령하지 않은 상자만 **좌표·시드 기반 결정적 20%**로 1개 추가. 일반 지상 상자, 플레이어가 다시 설치한 상자는 방독면 추첨 불가.
- 마스크는 가방 속 아이템을 소모하지 않고 '착용 상태'만 별도로 구분·저장하는 방식. 선택된 방독면 상태에서 화면의 `방독면 착용` 버튼을 눌러 장착·해제. 내구도·필터 소모·전체 장비 시스템 추가 없음.
- 마스크 아이템을 가방·커서 모두에서 없애면 즉시 해제. 사망 시 원래 소지품을 기존 사망 가방으로 한 번만 처리하고 착용 플래그를 해제. 저장·재접속 시 착용 플래그와 소지 여부를 검증. 여러 방독면을 소지하면 기존 boolean 착용 상태는 특정 개체 ID와 연결되지는 않으며, 적어도 1개를 보유하고 있을 때만 유지됨.

## 저장 구조 및 호환

- 저장 `version:2` 유지, 월드 기본 `generationVersion:6` 유지. 신규 지형·블록 숫자 ID는 추가하지 않음. 기존 세이브와 과거 월드 생성 버전 1~6 코드 그대로 유지.
- 신규 선택적 항목: `stage5:{version:1,nextStart,exposure,debuffRemaining,maskEquipped,phase,elapsedDays}`. `elapsedDays`는 누적 `meta.worldElapsedSeconds`에서 유도하는 정수, 핵심 기준은 기존 누적 시간 필드.
- 저장 시 기존 Stage 4 착유 쿨다운도 보존. 우유를 마시고 병을 반환하는 이전 트랜잭션은 건드리지 않음.
- 신규 저장 필드는 실질적인 범위를 검증하고 손상된 필드명을 명시하여 오류 처리. 구저장은 `stage5`가 없어도 복원 가능.

## 테스트 및 남은 검증

- `npm test`에서 1~4단계 기존 검사와 신규 테스트 통과. 기존 생성 버전의 해시, 저장 v1/v2 이주, 신규 선택적 저장 상태 및 마스크 보존, 실내 연결, 시간·수면 일정, 피폭·치료·재노출, 폐광 전용 1회 보상을 검증.
- Node JS 구문 검사, JSON/SVG 파싱, 정적 HTTP 리소스 응답 검사 통과.
- 실제 Chrome/Android 조작 및 시각 검증, 사용자의 원본 세이브 로드 검증은 **미완료**. 이번 환경의 Chromium은 로컬 탐색을 `ERR_BLOCKED_BY_ADMINISTRATOR`로 거부했으므로 '브라우저 완료'로 보고하지 않음.
- 6단계는 치와와 외형과 모바일 UI 회귀, 7단계는 실기 통합 테스트/최종 ZIP 납품. 사용자 승인 전 미진행.
